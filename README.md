# 学期手记 · Semester Planner

一个轻量的学期日程与手记工具。Python 3.12+ 标准库、SQLite、原生 HTML/CSS/JavaScript；无需 npm 构建、第三方运行库或外部字体。

## 功能

- 16 周教学 + 2 周考试的日历看板、今日安排、移动端布局。
- 单日/跨日任务与分钟级时间安排；跨日条块自动填补空位；拖动后预览新时间再确认。
- 任务详情的“节点”标签集中展示节点，点击添加或编辑按钮后弹窗设置，支持删除；节点按自己的日期显示为日历色块，支持周、今日与学期视图，点击可直接进入节点页。
- 任务详情支持“复制任务”：预填内容、分类、计划时间、DDL、节点和备注，修改后保存为独立新任务；新副本的任务和节点均重置为未完成。
- 新建分为任务内容和计划时间两步；任务详情、独立 DDL、备注、完成状态与删除撤销。
- 自定义分类及颜色；每类独立设置黄色/红色截止提醒阈值。默认 7 天/2 天，逾期红色，远期跟随分类色。
- 每日手记、公共课程模板、一键导入个人课表；课程和手记不计入任务统计。
- 管理员、普通账户和只读展示账户；账户汇总、用户名修改、密码重置。
- 按分类、日期、手记、课程和导出权限分享；仅占用模式隐藏任务细节与 DDL。
- 展示账户专用的只读 Dashboard API：可按日期读取授权日程及实际课程，并提供学期与分类元数据；独立 Token 可轮换和撤销。
- 浏览器本地 PNG 导出、JSON 归档和服务端 SQLite 备份。
- 原位滑动确认、电脑端直接确认、失焦取消；内容修改使用版本检查避免覆盖。

## 快速体验

```sh
python3 app.py --demo
```

打开 <http://127.0.0.1:8765/>。演示账号 `demo`，密码 `SemesterDemo2026!`，仅供本地体验；首次创建的账号为管理员。

示例任务、课程名和教室均为虚构。示例学期从 2026-09-07 开始，不代表任何学校的官方校历，可在学期设置中调整。`--demo` 只在演示账号不存在时创建数据，不覆盖已有账号。

数据库默认保存于 `data/planner.db`。正式环境请使用另一个空数据库，不使用演示凭据。

```sh
PLANNER_DB=./data/production.db python3 app.py --create-user admin
PLANNER_DB=./data/production.db python3 app.py
```

密码由终端交互输入。首个账户为管理员，至少 12 位密码；普通/展示账户至少 4 位，可使用更长密码。管理员重置别人密码时验证的是管理员自己的密码。

## 手机入口

`/m/` 提供独立手机界面，使用相同账户和数据。首页在首次加载宽度不超过 700px 时自动进入手机版；进入后横竖屏变化不会重建页面或丢弃草稿。手机“更多”中的“使用电脑版”可在当前标签页保留电脑布局，电脑页底部可切回手机版。

手机底部为“日程／总览／更多”：日程默认今天，总览内切换七天摘要和学期周列表，管理功能集中在更多。任务、课程和手记使用全屏页面；截止、备注和节点先编辑到任务草稿，最终滑动确认才提交。所有业务写入继续使用滑动确认，任务和手记保留版本冲突保护。手机关闭原生任务拖拽，使用“调整时间”改期；截止及节点不随计划区间移动。

手机只读分享继续由服务端裁剪，图片导出仍为学期快照。360／390／430px 布局及隔离数据主要写入流程已检查；真实 Android／iPhone 的软键盘、安全区和系统手势仍需设备验收。

## 配置与数据

| 配置 | 默认值 | 用途 |
| --- | --- | --- |
| `PLANNER_DB` | 项目下 `data/planner.db` | SQLite 路径 |
| `PLANNER_SECURE` | 未启用 | HTTPS 部署时设为 `1`，启用 Secure Cookie |
| `--host` | `127.0.0.1` | 监听地址 |
| `--port` | `8765` | 监听端口 |

日期与时刻按北京时间理解。任务计划区间与截止时间相互独立；完成任务不再显示紧迫色。

`n` 为黄色天数、`E` 为红色天数，要求 `0 ≤ E ≤ n ≤ 3650`，按距离 DDL 的实际剩余时长判断。

`timetable.json` 是新数据库默认模板的初始化种子。已有数据库使用数据库内模板；修改文件不会覆盖线上课表。新版课表设计器位于 `/timetables/`，提供课程列表、周课表与时段表单，手机按天展示。每门课程有稳定课程 ID 和多个固定时段，支持起止周、单双周、节次或具体时刻；同名课程只有明确归并后才共用课程身份。

管理员可维护多份课表，分别设置作息、停课日期，以及查看导入和协作编辑权限。授权编辑者可编辑指定课表内容，授权设置仍由管理员管理。新模板默认仅管理员可用；旧公共模板迁移为“默认课表”，保留原普通账号的读取与导入权限。

个人可以合并导入多份模板。模板修改通过“导入／更新”预览差异后进入个人副本；未个人改动的字段跟随源更新，个人改动默认保留，可逐项选择覆盖。停课规则只作用于所属来源；撤销模板授权或归档模板后，保留已有副本和个人记录，但不能继续获取源更新。旧 `course_id` 原样保留为时段 ID，既有调课、备注和作业不会因课程归并而改变关联。

课程详情提供调课、取消、恢复及安排补课，课程列表提供额外加课。关联补课沿用原课次的备注和作业；额外加课独立记录。节假日停课记录也可选择补课，显式调课或补课经确认后可安排到停课日期。取消关联补课后原课仍停课，恢复原课表需单独确认。当前补课和调课限定个人学期 18 周内，时间为北京时间。改变星期、周次或学期起始日时，已有个人记录的旧课次保留原始安排及查阅入口。

新版课程详情支持每次课独立的备注、“本次课需交作业”勾选项及作业说明。勾选后可设置“作业已完成”，课程名后显示小圆框 HW 标记：未完成为淡棕色，已完成为灰绿色；打开课程后的“详细信息”页集中展示安排、备注、交作业状态和说明，后续标签页用于修改设置。取消勾选会隐藏提醒并保留说明草稿；备注和作业设置与个人调课记录独立，恢复时间、重新导入课表后仍保留，仅本人可见。

完整 JSON 归档使用 `format: 2`，包含个人课程结构、导入来源快照、补课、历史课次、备注与作业，以及原有任务和手记；不应用自选筛选，本次不提供恢复导入。数据结构、接口边界和验收规则见 [课表设计方案](docs/COURSE_PLANNER_DESIGN.md)。

普通账户的数据按 `user_id` 隔离，共用一个 SQLite 文件，并非每人一个数据库。展示权限在服务端过滤，前端隐藏不是权限边界。

## 分享行为

所有者为每个绑定的展示账户单独授权，默认关闭。可分享本周、两周、学期或自定义范围；日历只展示授权日期。新增分类不自动分享；分类重命名或删除后需要重新授权。

仅占用模式：分钟任务与课程显示时间段；单日日期任务汇总为“另有 N 项安排”，跨日日期任务保留“另有安排”条块；不返回原标题、分类、备注、手记正文或 DDL。

展示页定期复核权限；暂停后续访问不能撤回已阅读或下载内容。导出开关只控制内置导出入口，无法阻止截图。

## 独立 Dashboard 接入

给 dashboard 分配一个展示账户：管理员先绑定账户，日程所有者设置允许展示的分类、日期范围和课程，然后在“分享管理 → Dashboard 只读 Token”生成凭据。Token 只显示一次，存放在 dashboard **服务端**，由它请求 planner；不要写进浏览器代码。轮换或撤销 Token 不影响展示账户的网页登录。

只读接口为 `GET /api/v1/agenda?from=YYYY-MM-DD&to=YYYY-MM-DD` 和 `GET /api/v1/agenda/meta`，都使用 `Authorization: Bearer <token>`。前者返回范围内的授权任务、实际课程及 DDL，后者返回学期和可见分类信息。分享设置始终是权限上限；暂停分享返回空日程。完整参数、字段、错误码、脱敏规则及调用示例见 [Dashboard API 说明](docs/DASHBOARD_API.md)。

例如，dashboard 服务端可请求 `GET /api/v1/agenda?from=2026-09-15&to=2026-09-20&include=tasks,courses`。日期包含首尾，单次最多 31 天；课程已经展开为具体日期。`meta` 可用于显示学期名称和可见分类。两个接口都只接受 `GET`，并使用展示账户现有的分类、日期、已完成、备注、课表及仅占用授权。若要展示“未来 DDL”，dashboard 从已获准返回的任务中按 `due` 筛选；查询计划日期范围外的任务不会因其 DDL 落入范围而自动返回。

## 当前限制

没有后台推送、重复任务、附件、离线编辑或网页 JSON 导入。PNG 是静态快照，当前导出与屏幕排版并不完全一致；一般账户需刷新读取其他设备的修改。

自带 HTTP 服务用于个人或小范围受控部署，不是经专业审计的公共 SaaS。公网使用需配置 HTTPS、代理限速、备份和访问策略。

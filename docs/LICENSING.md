# 许可证选择（尚未生效）

推荐 MIT：对于轻量个人工具，授权简洁，方便他人部署、修改与复用，也允许商业使用；再分发时须保留版权与许可声明。它不要求修改版开源。

如果更希望修改版作为网络服务提供时也向使用者提供对应源代码，可考虑 AGPL-3.0。它适合重视持续开放的软件服务，但对接入其他项目的许可兼容性要求更高。

本文件只是选择说明，不是授权文件。维护者选定之后再加入根目录 LICENSE，并确定版权年份及署名，不使用猜测的身份信息。

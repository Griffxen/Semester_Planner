# 新版前端与过渡

## 设计主线

总览使用有限的视觉容量承载摘要，详情通过浅层导航展开，操作通过原位确认保护。页面纵向长度与操作入口深度需要同时控制：不能靠无限增高任务块展示信息，也不能把常用操作藏进多层菜单。

首版提供三个视图：今天、本周、学期。桌面默认本周，手机直接进入今天。视图切换、定位今天和筛选入口常驻；具体筛选按需展开。桌面持续任务按照日期区间排入可共用的轨道，电脑端高度固定 44px（手机 48px），顶部是名称与计划/截止摘要，底部是节点轨道；节点名称、日期、时刻和状态紧邻标记。相近节点合并并显示额外数量，过密标签只保留标记，完整内容在任务详情的节点页查看。手机本周用七个日期标签切换单日，避免默认铺开七天的全部内容。

今天页支持前后一天导航。日程混合课程和定时任务并按时间排序，持续任务在同页独立区域并列，手机上下排列。未完成的逾期与当天截止、节点进入独立待办提醒区，完成后自动消失；手记保留同层标签。电脑端学期页默认展开全部周；手机保留按周折叠，默认展开当前周，学期外任务保留独立入口。每日任务和课程完整显示，不以“另有 N 项”截断。统计明确为全学期，采用四张紧凑卡片、标签与数字分层，并恢复学期进度条；搜索覆盖标题、简称、备注和节点名称。

任务详情分为概览、节点、备注；同一窗口切换标签时保持外框尺寸与操作区位置，长内容在内部滚动。编辑、调时、完成与删除直接可达。创建和编辑使用内容、时间、节点、确认提交四个同层标签，共用草稿，只有最终确认页可以提交。账户设置以修改用户名/修改密码标签替代操作下拉菜单，个人资料有直接入口，管理员操作进入账户管理。课程以我的课表/公共模板/临时调整/管理员模板管理分层，模板管理内再用课程模板、停课日期标签。课程取消为独立按钮，调整表单只编辑日期与时间。分享使用账户列表和单账户编辑页，编辑页分分享范围、展示内容、Dashboard 接入。管理员创建、绑定与登录状态管理集中到账户管理的展示账户页。

关键操作沿用按钮首次点击、原位滑块再次确认的机制，并保留角落低调的直接确认。确认对象和影响在当前上下文中说明；键盘可以用右方向键后 Enter 完成第二次确认，Esc 取消。无修改关闭分类管理直接退出；有未保存修改才确认放弃。

需要验证当前密码的操作使用独立身份验证窗口，暂时替代业务表单，取消后恢复原表单。当前密码只用于此次提交，不保存在浏览器存储，不默认短时免验证。服务端仍使用既有接口对密码、权限、CSRF 和提交内容进行检查；没有新增绕过验证的接口。前端收集身份凭据与后端验证/变更属于同一次受保护提交。

图标以本地 SVG 路径构成一致的线条系统，与功能文字配合使用；没有引入外部图标网络依赖。

## 入口与备份

2026-10-14 根据首轮使用反馈调整：每日安排不再截断，电脑端学期默认全部展开；新版设为默认首页。统计从通栏恢复为低高度卡片，旧版入口降为无边框的小号文字链接。低频设置与导出移入独立的同层标签窗口，侧栏不再展开整排操作。内容切换统一使用标签栏和选中下划线。深色日历采用中性底色，今天只在日期标题处强调；课程没有嵌套深色按钮底，任务分类色采用轻染与边线。普通任务、课程和持续任务采用一致的紧凑两行布局，电脑端 44px、手机 48px。任务详情、账户与课程窗口在同层标签切换时保持尺寸；任务详情的长内容在内部滚动，底部操作区保持原位。

| 路径 | 行为 |
| --- | --- |
| `/` | 新版默认首页，提供旧版切换入口 |
| `/next/` | 新版前端，提供“切回旧版”入口 |
| `/legacy/` | 旧版快照，仅适配本地资源路径及新版入口 |

三个入口共用现有登录会话和后端数据。切换版本不会复制、迁移或删除日程；两版的修改都会写入同一账户的数据。新版作为默认首页；旧版始终保留独立入口，不移除。

`static/legacy/original.html` 是改造前首页原文件；其他原资源保存于同目录，`SHA256SUMS.json` 记录原文件哈希。`legacy/index.html` 为可访问的适配入口。新版复用冻结的旧版业务客户端，再由 `static/next/app.js` 提供新的呈现与交互层；这是保留既有功能的过渡结构，后续可逐步提取独立模块。

此次后端改动仅增加静态资源白名单路由。Dashboard 节点兼容改动先以 `cc73242` 单独提交。现有密码校验、分享过滤、课程例外、任务版本检查与数据语义保持既有规则。

## 部署与回退

部署前备份服务器代码和 SQLite 数据库，核对前后源码差异；停止应用服务后安装代码及资源，校验语法与文件哈希，再启动服务。发布后的生产验证以 GET 和只读浏览为主，不创建测试任务。

用户随时使用旧版入口继续工作。服务器发布失败时恢复部署前代码并重启；数据库备份单独保存，不因前端回退而默认覆盖发布后的新数据。

| 发现 | 修正及验收 |

# 结构与设计

- `app.py`：HTTP 入口、SQLite schema/迁移、账号、任务、分类、手记和课程 API。
- `sharing.py`：展示账号权限、个人状态与分享投影；过滤在服务端执行。
- `static/app.js`：日历、任务详情与分步表单、调时、提醒、确认交互、PNG 导出。
- `static/share.js`：分享设置与管理员展示账号绑定界面。
- `static/index.html` / `style.css` / `icon.svg`：页面结构、响应式布局与图标。
- `timetable.json`：虚构课程模板，仅用于新数据库初始化。
- `backup.py` / `deploy/`：SQLite 一致性备份及部署模板。
- `tests/`：临时数据库上的 API 和权限测试。

SQLite 中账户共库、按用户 ID 隔离；用户名不是数据主键，改名不改变归属。任务计划起止时间和 DDL 是不同字段。日期任务包含首尾日期，分钟任务要求结束晚于开始。

持续任务按周裁剪成条块，屏幕端将不重叠条块分配到同一行；不改变任务本身日期。分类阈值只控制 DDL 提醒，不限制保存。

分享先按授权分类、状态和日期裁剪，再进行占用模式脱敏；预览与展示账户复用同一投影。仅占用模式不包含 DDL。

页面 CSP 不允许 HTML 内联样式，因此动态颜色通过 DOM style 属性赋值；不要重新在 HTML 字符串中拼接 style 属性。

首批 Git 提交是按模块整理的当前实现快照，不是重建的历史开发记录。应用本身为完整基线提交，避免故意拆出缺少依赖、无法运行的中间版本。
